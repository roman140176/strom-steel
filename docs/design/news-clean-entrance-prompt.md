## Контекст бренда (дизайн-система)

- **Компания:** ООО «СТРОМ ТРЕЙД» — производство металлоконструкций, г. Москва.
- **Палитра:** брендовый зелёный `#0e7e50` (акцент), `#0a5e3b` (deep — тёмные блоки/CTA), нейтральные серые, тонкие линии `#e3e7e5`. Бывшие синие (`#1b4e9b`, `#1f34f2`) — **запрещены**.
- **Шрифт:** Inter (в проекте подключён глобально; в превью — `<link>` к Google Fonts). Для «чертёжных» акцентов (номера выносок, технические метки) допустим системный monospace (`ui-monospace, "SF Mono", monospace`).
- **Сетка — строго сайтовый `.container`** (свой контейнер НЕ изобретать). Реальных брейкпоинтов ровно два:
  - `≥1367px`: `width: 1320px`, центрирован (`margin: 0 auto`), `padding: 0`;
  - `≤1366px`: `width: 100%`, `padding: 0 15px` (резиновый, боковые отступы 15px).
  - Каждая секция — **full-width обёртка** (фон тянется на всю ширину) с `<div class="container">` внутри.
- **CSS-namespace:** все классы — префикс **`.nce-*`** (news clean entrance). Исключение — сама `.container`.
- **Адаптив:** явные брейкпоинты `≤900px` и `≤600px`.

## Визуальный язык (что делает страницу «инженерной» и небанальной)

1. **Blueprint-эстетика.** Тонкая техническая сетка/координатные линии на тёмных секциях, аккуратные выноски с точкой-пином и тонкой линией к элементу, моноширинные номера `01 / 02 / 03`.
2. **Зелёный — только как акцент** (активная выноска, линия фильтрации, ключевое слово), фон — нейтральный светлый или тёмно-стальной. Без пёстрых градиентов вне hero/CTA.
3. **Ось — схема и принцип.** Главные блоки (разрез + воронка фильтрации) визуально доминируют; текст и шаги — поддержка, сделаны легче и компактнее.
4. **Интерактив без JS.** Наведение/`:target` на выноску может подсвечивать соответствующий элемент схемы (CSS `:hover`/`:target`, без JavaScript). Hover-эффекты, плавные transitions — да. Никакого JS.
5. **Иконки и схема — inline SVG**, stroke 1.5–2px, тонкие линии.

## Структура страницы (8 блоков, ось — «анатомия»)

- Внизу — тонкая полоса метаданных: дата · ~2 мин · «Реализованные проекты».

### 2. Лид — вступление (редакторский, асимметричный)

Крупный абзац (~22px), прижат влево (≈8/12), тонкая зелёная вертикальная линия слева. Eyebrow «Главное».

### 3. «Задача» — две зоны (короткий блок)

Светлый блок. Eyebrow «Задача». H2 «Две зоны на пути в офис».
- Текст: «Проблема грязных полов в офисах особенно актуальна в межсезонье. Решает её система очистки обуви на входе. В этом проекте „СТРОМ ТРЕЙД" сосредоточилась на двух зонах входной группы — **уличной** и **зоне тамбура** между наружной и внутренней дверями».
- **Акцентная врезка** (зелёная полоса слева): «Именно зона тамбура отвечает за финальную очистку: здесь обувь избавляется от средних частиц — песка и мелких камешков — и теряет остатки влаги».

### 4. ⭐ ЯДРО — «Анатомия входной группы» (аннотированная SVG-схема-разрез)

**Главный экран страницы.** Крупная **inline-SVG схема входной группы в разрезе** (стилизованная, не фото): слева уличная зона, справа — тамбур и вход в офис. Показать слои/элементы и протянуть к ним **пронумерованные выноски** (точка-пин + тонкая линия + метка):

| № | Элемент | Подпись у выноски |
|---|---|---|
| 01 | **Стальная решётка** | Первая ступень: снимает крупные фракции грязи, снег и наледь ещё до входа. |
| 02 | **Профиль-фундамент** | Надёжная опорная конструкция — «фундамент» из прочного металлического профиля под решётку. |
| 03 | **Алюминиевый ковёр** | Основа второй зоны — в тамбуре между наружной и внутренней дверями. |
| 04 | **Скребки** | Очищают подошву от песка и мелких камешков. |
| 05 | **Текстильные вставки** | Впитывают остатки влаги, не давая ей разойтись по полу. |

- Стиль выносок — чертёжный: моноширинный номер в кружке/квадрате, тонкая линия к точке на схеме.
- **CSS-интерактив (опционально, без JS):** при `:hover` по выноске соответствующий элемент схемы подсвечивается зелёным (или `:target` через якоря-номера). Обязателен fallback — без hover всё читается.
- Под/сбоку — легенда: «Две зоны · пять элементов · одна задача — остановить грязь на входе».
- На мобиле: схема масштабируется, выноски переезжают в вертикальный список под ней (номер → метка → подпись).

> Названия элементов **не искажать**: «стальные решётки», «алюминиевые ковры с текстильными вставками и скребками».

### 5. «Три ступени фильтрации» — инфографика-воронка

## Технические требования к выдаче

- **БЕЗ ХЕДЕРА, ФУТЕРА И ХЛЕБНЫХ КРОШЕК** — глобальный layout оборачивает страницу сам, крошки даёт Yii-виджет. Нужен **только контент-блок** от hero до «← Все новости». Без своей навигации/меню/копирайта/sidebar/тегов/комментариев/share.
- **Сетка — через сайтовый `container`.** В превью добавить заглушку, помеченную комментарием:
  ```css
  /* PREVIEW ONLY — на сайте .container уже определён, при интеграции удалить */
  .container { width: 1320px; margin: 0 auto; padding: 0; }
  @media (max-width: 1366px) { .container { width: 100%; padding: 0 15px; } }
  ```
- **Формат:** один самостоятельный HTML-файл — `<style>` (правила только в `.nce-*`) + разметка.
- Только семантические классы (`.nce-hero`, `.nce-anatomy`, `.nce-callout`, `.nce-funnel`, `.nce-process`, `.nce-mosaic`, `.nce-cta`…), без Tailwind-утилит — чтобы стили легко переехали в `themes/default/web/css/custom.css`.
- Схема-разрез и иконки — **inline SVG** (не картинки), stroke 1.5–2px.
- Фото — Unsplash-плейсхолдеры (steel floor grating / entrance mat / office lobby / metal fabrication / snowy entrance).
- **Только HTML+CSS, без JavaScript.** Допустимы `:hover`/`:target`-подсветка, `position: sticky`, transitions. Никакого JS.
- Адаптив `≤900px` и `≤600px`: схема масштабируется и выноски → вертикальный список; воронка и процесс-лента → стек; мозаика → 2 кол → 1 кол; hero ниже; типографика мельче.

## Что обязательно сохранить из исходного текста (перефраз ок, смысл — точно)

1. «Хотите забыть о грязных следах в офисе после дождя или снегопада?» + «продуманные решения для защиты помещений от уличной грязи» (лид).
2. Это **кейс**: «недавно реализовали очередной успешный проект в Москве».
3. Проблема грязных полов актуальна **в межсезонье**; решение — система очистки обуви на входе.
4. Две зоны: **уличная** и **зона тамбура** (между наружной и внутренней дверями). Тамбур = финальная очистка: средние частицы (песок, мелкие камешки) + остатки влаги.
5. 3 шага: выезд + точные замеры → индивидуальные чертежи входных зон → подбор оптимального оборудования.
6. Оборудование (названия **не искажать**): уличная зона — **стальные решётки**; тамбур — **алюминиевые ковры с текстильными вставками и скребками**.
7. Решётки — первая ступень: крупные фракции, снег и наледь **до входа**; на надёжных опорных конструкциях — «фундаменте» из прочного металлического профиля.
8. Текстильные вставки впитывают влагу; скребки очищают от песка и камешков; конструкция **исключает застревание каблуков**.
9. Результат: установлено **в срок**, заказчик доволен, полы чистые **даже в самую ненастную погоду**.

## Чего НЕ делать

- Не выдумывать цифры/факты (никаких «500+ объектов», «лет на рынке», процентов, гарантийных сроков) — статистики в тексте нет.
- Не добавлять цитат от сотрудников — их в исходнике нет.
- Не повторять каркас прошлой новости (hero→шаги→карточки→CTA) — ось здесь «анатомия/схема».
- Не вставлять формы/капчу — только кнопку под глобальную модалку.
- Жирные градиенты — только в тёмном hero и тёмном CTA.
- Никакого JavaScript.
