# Промпт для Claude Design — страница новости «Системы водоотведения из нержавейки „под ключ"»

**URL:** `/news/sistemy-vodootvedeniya-iz-nerzhaveyki-pod-klyuch`
**Тип:** промо-новость компании (lead → этапы «под ключ» → продукция → выгоды → доверие → CTA)
**Цель:** превратить рекламный текст в визуально насыщенную продуктовую новость уровня корпоративного блога. Подача — индустриальная, чистая, профессиональная. Это не кейс и не пресс-релиз, а **продающая новость про услугу**.

> - Анонс для главной: «СТРОМ ТРЕЙД: системы из нержавейки — от замеров до монтажа»

## Контекст бренда (для дизайн-системы)

- **Компания:** ООО «СТРОМ ТРЕЙД» — производство металлоконструкций, г. Москва
- **Брендовый зелёный:** `#0e7e50` (основной акцент), `#0a5e3b` (deep — для тёмных карточек)
- **Шрифт:** Inter (уже подключён в проекте — preconnect + Google Fonts)
- **Сетка:** сайтовый класс **`.container`** — фиксированные `1320px` на десктопе, `100%` + `15px` боковые отступы ниже `1366px`. **Собственный контейнер не изобретать** — каждая секция верстается как full-width обёртка (фон на всю ширину) с `<div class="container">` внутри.
- **Стиль:** индустриальный, технологичный, чёткие сетки, тонкие линии, hover-lift эффекты. Визуальный язык — как на service-страницах сайта (карточки с тонкой рамкой, зелёные акцентные полоски, тёмные hero/CTA).
- **CSS-namespace:** все классы префиксовать **`.nwd-*`** (news water drainage) — изолировать от легаси-стилей сайта. Исключение — сама `.container` (сайтовая).
- **Адаптив:** breakpoints `≤900px` и `≤600px`

## Технические требования к выдаче

- **БЕЗ ХЕДЕРА И ФУТЕРА.** На сайте уже есть глобальный layout (шапка с логотипом/телефонами/меню и футер) — он автоматически оборачивает страницу. Нужен **только контент-блок**: от hero до CTA и ссылки «← Все новости». Никакой собственной навигации, меню, копирайта.
- **Хлебные крошки — не рисовать**, они подключаются на уровне Yii-view через виджет `bootstrap.widgets.TbBreadcrumbs`.
- **Сетка — строго через сайтовый класс `container`:** каждая секция — full-width обёртка с фоном + `<div class="container">` внутри. В превью-HTML можно добавить минимальный стиль для предпросмотра, обязательно пометив комментарием:
  ```css
  /* PREVIEW ONLY — на сайте .container уже определён, при интеграции удалить */
  .container { width: 1320px; margin: 0 auto; }
  @media (max-width: 1366px) { .container { width: 100%; padding: 0 15px; } }
  ```
- **Формат:** один самостоятельный HTML-файл: `<style>` с правилами в `.nwd-*` namespace + разметка.
- Не использовать Tailwind utility-классы — только семантические (`.nwd-hero`, `.nwd-step`, `.nwd-product`, `.nwd-cta` и т.д.), чтобы стили легко переехали в `themes/default/web/css/custom.css`.
- Inter через `<link>` к Google Fonts (в проекте уже подключён глобально — в превью нужен для самодостаточности).
- Изображения — placeholder'ы Unsplash (`https://images.unsplash.com/...`) по темам stainless steel / industrial kitchen / factory drainage / metal fabrication. Реальные фото вставим позже.
- Адаптив: явно прописать `@media (max-width: 900px)` и `@media (max-width: 600px)` — сетки сжимаются, flow из шагов становится вертикальным, hero ниже, типографика меньше.
- **Никакого JavaScript** — только HTML+CSS. Кнопки — обычные ссылки; модалка подключится при интеграции.
- Иконки — inline SVG (не FontAwesome), stroke 1.5–2px, тонкие линии.

## Что обязательно сохранить из исходного текста

Можно перефразировать, но смысл и ключевые формулировки — сохранить:
1. «СТРОМ ТРЕЙД — ваш надёжный партнёр в оснащении объектов системами внутреннего водоотведения из нержавеющей стали» (lead)
2. Отрасли: пищевая, фармацевтическая, промышленная (hero-чипы + lead)
3. «Все этапы — от точных замеров до монтажа» (hero-подзаголовок + секция 3)
4. Номенклатура: ревизии/прочистки, трапы с горизонтальным или вертикальным выпуском, щелевые или стандартные лотки (секция 4) — **названия продукции не искажать**
5. «Мы не просто поставляем оборудование — мы предлагаем готовое решение „под ключ". Вам не придётся координировать разных подрядчиков» (секция 5)
6. «Рабочая система из нержавеющей стали для сбора и отвода стоков в канализацию, которая прослужит долгие годы» (секция 5)
7. «Высокое качество продукции, соблюдение сроков и профессионализм команды уже оценили наши клиенты из разных отраслей промышленности» (секция 6)
8. «Оставьте заявку — и мы поможем воплотить ваш проект в жизнь!» (CTA)

## Чего НЕ делать

- Не выдумывать цифры и факты, которых нет в тексте (никаких «500+ объектов», «25 лет гарантии» и т.п.) — статистики в этой новости нет.
- Не добавлять цитат от имени сотрудников — в исходнике их нет.
- Не использовать стоковые блог-шаблоны (sidebar, теги, комментарии, share-кнопки) — это корпоративная новость.
- Не вставлять формы/капчу прямо в страницу — только кнопку под глобальную модалку.
- Не использовать жирные градиенты вне тёмного hero и тёмного CTA — остальное чисто и сдержанно.
- Не применять бывшие брендовые синие (`#1b4e9b`, `#1f34f2`) — только зелёная палитра + нейтральные серые.

## Ожидаемый результат

Один HTML-файл с готовой вёрсткой контент-блока новости, который мы:
1. Сохраним в `docs/design/` (как референс).
2. Интегрируем через конструктор новостей: view = `constructor`, партиал `longread`, HTML-секции — в произвольные поля группы (пути к ассетам через плейсхолдеры `{{baseUrl}}` / `{{themeAssets}}`), либо как отдельную view по образцу `rebranding.php`.
3. Стили перенесём в `themes/default/web/css/custom.css` (namespace `.nwd-*` гарантирует отсутствие коллизий).
